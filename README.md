# Bi-Syntax Aware Graph Attention Network


This repository contains Pytorch implementation for "[PSA-GAT Integrating position-syntax and cross-aspect graph attention networks for aspect-based sentiment analysis)"  and PSCA_Position-Syntax_and_Cross-Aspect_for_Aspect-based_Sentiment_Analysis_in_One_Model"

## Requirements
```
python = 3.7
pytorch >= 1.7
transformers >= 4.3.3 
```
